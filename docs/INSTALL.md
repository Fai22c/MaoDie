# Install Maodie As A Codex Pet

Maodie is expected to live in:

`~/.codex/pets/maodie/`

That folder should contain:

- `pet.json`
- `spritesheet.webp`

The local completed pet is already installed at:

`/Users/wyx/.codex/pets/maodie/`

To select Maodie in Codex Desktop, edit:

`/Users/wyx/.codex/config.toml`

In the `[desktop]` section, set:

```toml
selected-avatar-id = "custom:maodie"
```

Then restart Codex Desktop.
